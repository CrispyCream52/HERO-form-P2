# MANTLE-original
Propósito: projeto acadêmico &amp; pessoal, website temático de DELTARUNE, para meu próprio uso.

Este é o projeto completo, somente para meu uso. Este trabalho não será disponibilizado como código aberto, portanto, ninguém possui a permissão de usar minha criação, sob qualquer forma ou formato.

## DECISÕES UX / UI

Principalmente, por gosto pessoal e pelos visuais simples que o jogo oferece, decidi que o estilo que mais combinaria com meu trabalho seria trabalhar com um design minimalista.
Meu pensamento inicial era sobre criar algo simples, mas bem feito - nada megalomaníaco ou que poderia estimular o usuário em excesso. O jogo por si próprio utiliza de apenas formas quadrangulares para se comunicar com o jogador, como caixas de diálogo, cutscenes e o menu, o que proporcionou uma maior facilidade na hora de pensar e elaborar a consistência do site. Outros princípios como Gestalt foram implementados, o menu de personagem e cada tópico / segmento está agrupado para relacionar seus elementos como um único item, sendo discernidos através de espaçamentos e títulos para a sinalização. Sobre o contraste de cores, fora um parte determinada bem antes de se quer o primeiro protótipo ser planejado, inicialmente pretendi fazer uma paleta para o design do meu personagem, posteriormente sendo reutilizado para se tornar o tema do website. Cada página e cada segmento foi organizado do mais para o menos importante na hierarquia que cada um estivesse inserido, concedendo uma legibilidade mais suave.

## NOTA DO DESENVOLVEDOR

Eu queria manter a identidade visual do jogo para fazer com que as pessoas que já experienciaram Undertale ou DELTARUNE pudessem sentir as boas memórias que um dia tiveram com essa obra. Este trabalho é muito mais que apenas um mero projeto acadêmico ou de uma chance de conseguir notas boas, é minha maior prova de respeito ao universo que Toby Fox nos presenteou. Cada segredo, opção de design e história foi feito com uma paixão ardente, uma na qual ninguém conseguirá apagar.
